# ShadowFaction 

**ShadowFaction** is a simple browser-based action game where the player fights against waves of enemies. The goal is to survive, defeat enemies, and get the highest possible score.

##  Features

* Player movement using keyboard controls
* Mouse aiming and shooting
* Enemies that chase the player
* Bullet and enemy collision system
* Health system
* Score system
* Wave-based enemy spawning
* Game Over and Restart system
* Touch controls for supported devices
* Dark/shadow-themed game interface

##  Controls

### Keyboard

* **W / A / S / D** — Move
* **Arrow Keys** — Move

### Mouse

* **Mouse** — Aim
* **Hold Mouse Button** — Shoot

##  Tech Stack

* **HTML5** — Game structure and Canvas setup
* **CSS3** — Styling, layout, HUD, and visual design
* **JavaScript** — Game logic, player movement, shooting, enemies, collisions, health, score, waves, and game loop
* **HTML5 Canvas API** — Rendering the game graphics
* **VS Code** — Development environment

##  How to Run

1. Download or clone the project.
2. Open the project folder in **VS Code**.
3. Open `index.html` in a web browser.
4. Start playing!

You can also use the **Live Server** extension in VS Code for easier development.
